# 开题报告

**课题名称：**基于计算机视觉与大语言模型的网球动作智能教练系统  
**学生姓名：**栾乐礼	

## 一、课题研究的目的和意义：

网球技术动作要求严格，正手击球、反手击球、发球、截击等核心技术均对关节角度、身体姿态有精确要求。传统网球教学高度依赖教练现场指导，无专业教练时运动员难以获得客观、量化的动作反馈，自我纠错效率低下。

本课题旨在开发基于计算机视觉与AI的网球动作智能教练系统，通过分析运动员动作照片，自动提取人体关键点，计算关节角度，与标准技术模板比对，给出量化评分与个性化改进建议。

**研究意义：**
1. **降低专业指导门槛：**通过AI自动分析替代部分人工教练工作，使普通爱好者也能获得客观技术反馈
2. **实现量化评估：**将主观、定性的动作评价转化为可量化的角度偏差和百分制评分，便于运动员追踪自身进步

## 二、研究内容、关键问题、研究方法、技术路线：

### 【1】研究内容

系统主要包含六个核心模块：

1. **人体关键点检测：**识别运动员照片中的17个人体关键点（头顶、肩、肘、腕、髋、膝、踝等），支持百度人体分析云端API与MediaPipe Pose本地离线模型两种方案
2. **关节角度计算：**基于关键点坐标，计算核心关节角度，包括右肘角、左肘角、右肩角、左肩角、右膝角、左膝角及躯干倾斜角
3. **标准模板构建：**使用12种网球动作（正手/反手/发球/截击各阶段）分别训练标准模板，多样本自动取均值以提升模板精度
4. **动作评估与反馈：**将学员动作角度与最匹配的标准模板进行对比，依据预设偏差阈值识别问题关节，生成0—100分的量化评分及改进建议文案
5. **多模态语义分析：**可选接入通义千问视觉语言大模型（qwen-vl-max），对握拍方式、击球点位置、眼神等难以用角度量化的技术细节进行自然语言分析
6. **学员进度管理：**持久化存储每次评估记录，支持按学员姓名查询历史数据并可视化进度曲线

### 【2】关键问题

1. **关键点检测精度与鲁棒性：**不同拍摄角度、光线条件下，如何保证人体关键点的准确识别
2. **动作阶段自动匹配：**学员上传照片时无需手动选择动作类型，系统如何通过RMSE最小化策略自动判断当前动作阶段
3. **角度阈值的合理设定：**不同关节、不同动作阶段的角度容差不同，阈值过严会误报，过松则无法有效纠错，需结合专业知识精细调校
4. **双方案融合与降级策略：**百度API依赖网络，MediaPipe依赖图片质量，如何保证系统在不同环境下均可正常运行

### 【3】研究方法

- **文献调研：**查阅人体姿态估计、体育动作分析相关论文，了解主流方法与评估指标
- **工程实现：**采用Python全栈开发，后端基于http.server搭建轻量API服务，前端使用纯HTML/CSS/JavaScript实现，无需额外框架，降低部署复杂度
- **实验验证：**收集真实网球动作照片，分别用两种检测方案进行测试，对比检测精度与评估合理性
- **迭代优化：**根据实测结果调整角度阈值与建议文案，逐步提升系统反馈质量

## 三、预期的研究成果和创新点：

### 【1】预期研究成果

1. 可运行的网球动作智能教练系统：具备训练、评估、对比、进度追踪四大功能模式，支持12种网球动作的分析
2. 标准动作角度模板库：收集并整理正手击球、反手击球、发球等主要技术动作的标准角度数据集
3. 系统测试报告：对百度API与MediaPipe两种方案在不同图片条件下的检测精度、稳定性进行对比分析

### 【2】创新点

1. **双引擎检测架构：**同时支持百度人体分析云端API与MediaPipe本地离线模型，两种方案可并排对比，也可在网络不可用时自动降级，保障系统可用性
2. **几何量化与语义理解相结合：**传统基于规则的角度分析与多模态大模型的自然语言理解相结合，既能给出精确的关节角度偏差，又能针对握拍等难以量化的细节提供语义层面的建议
3. **增量式均值模板训练：**标准模板支持多张照片逐步训练，每次新样本自动与已有样本取加权均值，无需重新训练，模板精度随样本积累持续提升
4. **全身动作自动阶段识别：**学员上传照片无需手动标注动作类型，系统通过计算学员角度向量与所有模板的RMSE，自动匹配最接近的动作阶段，降低使用门槛
